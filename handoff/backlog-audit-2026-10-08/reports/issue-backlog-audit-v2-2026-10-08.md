## Two columns: implementation status and ownership

**Implementation status** (what the code shows):
- IMPLEMENTED: all mandatory criteria met on main.
- COVERED by open PR: an open or draft PR covers the remaining scope. Not yet on main.
- PARTIAL: some criteria met; the remaining requirement is written in the row.
- NOT STARTED: no PR, no code change on main.
- DEFERRED: research, dataset processing or a large refactor.
- UNCERTAIN: evidence or access is missing.
- NOT ANALYSED (owned), OUT OF SCOPE: excluded by brief.

**Ownership** (who may act):
- **Assigned**: named in the brief (Master 1 for Benchmark #123; Master 2 for Description #138 and EUNIS #108 assessment).
- **Partially assigned**: a named slice is owned; the remainder is not available.
- **Existing owner**: golden #43 to #46, already owned.
- **In flight**: an open or draft PR is working on it. Not available.
- **Owner hold**: the repo owner has paused, deferred or gated the work in a comment, or it awaits the owner's closure decision.
- **Approval needed**: an external write (publishing datasets) that needs owner approval.
- **Blocked**: an open PR overlaps the scope or must merge first. Named in the row.
- **Blocked (access)**: a repo or resource this session cannot read.
- **Unowned**: no claim, comment, PR or branch found. The only class that is available without someone releasing it, subject to the other columns.
- **Unknown**: presumed Master 1 queue (maintenance). Membership in Master 1's queue is not visible to me. Treat as Master 1's until Master 1 releases it.
- **Out of scope**: Grid'5000 or another excluded area.
